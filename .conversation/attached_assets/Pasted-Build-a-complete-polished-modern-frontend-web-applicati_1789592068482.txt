Build a complete, polished, modern frontend web application for my project:

PRODUCT NAME:
DriveOps-AI

PRODUCT TITLE:
Smart Car Manufacturing & Production Intelligence System

TAGLINE:
Turning Manufacturing Data into Actionable Intelligence

IMPORTANT:
This is a college-level product prototype, so the UI must look professional, attractive, modern, and product-ready — NOT like a basic student dashboard.

At the same time, the application must remain very easy for beginner users to understand and operate.

The frontend should be built using React + Vite.

==================================================
1. CORE PRODUCT IDEA
==================================================

DriveOps-AI is a smart manufacturing intelligence platform designed for automobile manufacturing environments.

The system works with manufacturing data from:

- Machines
- Production lines
- Quality inspections

The backend analyzes this data and identifies:

- Abnormal machine conditions
- Production performance issues
- Quality issues
- Overall manufacturing risk

The system can generate:

- Alerts
- Manufacturing insights
- Recommended actions

The frontend should present these results clearly to operators, supervisors, production managers, maintenance teams, and quality teams.

IMPORTANT:
Do NOT expose backend implementation details such as:

- AI agents
- Master Agent
- Machine Monitoring Agent
- Production Intelligence Agent
- Quality Intelligence Agent
- SNS Agent Workbench
- n8n
- workflow nodes
- LLM configuration
- prompts
- API implementation

These are backend details.

The frontend should show the RESULT of the intelligence, not the technical implementation.
